# 微信提醒助手

独立的 Windows 微信关注提醒工具，非腾讯官方产品。默认没有托盘图标、没有日常主窗口；需要设置或退出时，从开始菜单打开“微信提醒助手”，或双击程序。

**发布候选 0.2.0-rc.1，尚非跨机器全面验证的稳定版。** 不修改微信安装文件，不注入、不读取聊天或联系人，不获取账号凭据。

## 它能做什么

- 观察同一 Windows 用户、同一会话下，经过本地签名核验的官方微信公开“请求关注”事件，交给 Windows 通知系统。
- 系统通知中提供通用提醒，不提供联系人、消息正文或精确会话跳转。
- 点击通知时，可使用你亲自确认的微信“显示/隐藏窗口”快捷键，尝试打开已经运行的微信。不会注册全局快捷键，不展开隐藏托盘菜单，也不会为了唤回而重新运行微信程序。
- 已在前台时不重复切换；版本/文件变化、输入桌面异常、按键正被使用或重复失败时会安全停止唤回。

**它不是逐消息监听器。** 微信未请求系统关注时可能没有提醒；短时间连续事件会合并。不能全面消除与微信自身通知重复的情况。Windows 勿扰/全屏状态可能只静默放入通知中心，系统禁用通知时不发送。不会绕过系统抑制。

## 下载和安装

1. 本候选仅提供 **Windows x64，框架依赖版本**。推荐 Windows 11；编译 API 下限为 Windows 10 build 19041，但 Windows 10 尚未实测，不作兼容承诺。ARM64/x86 暂不支持。
2. 先安装微软 **.NET 10 Desktop Runtime x64**（不是 SDK，也不是仅 ASP.NET Runtime）。只从[微软官方下载页](https://dotnet.microsoft.com/download/dotnet/10.0)获取。安装说明见[微软文档](https://learn.microsoft.com/dotnet/core/install/windows)。本包不包含这个运行时，不会自行下载或购买任何东西。
3. 下载发行 ZIP，右键选择“全部解压缩”。**不要直接在 ZIP 中运行程序。** 对照发行页提供的 SHA-256 校验包完整性；校验和不是代码签名，也不能证明下载来源可信。
4. 双击 `Install.cmd`。它只安装到当前用户的 `%LOCALAPPDATA%\Programs\WeChatNotify`，不需要管理员，不修改系统安全策略。脚本仅在本次 PowerShell 进程指定执行策略；企业策略仍可能禁止执行。
5. 在设置中阅读说明，勾选同意并保存。登录自启默认不选。需要通知点击唤回时，先在微信设置中查看“显示/隐藏窗口”实际快捷键，输入对应的 `Ctrl+Alt+字母` 并勾选确认。不同人的组合键可能不同；没有配置也可接收提醒。

也可直接从完整解压目录运行 `WeChatNotify.exe` 作为便携工具。通知注册和配置仍属于当前 Windows 用户。使用期间不要移动目录；移动后先在旧位置卸载，再从新位置安装/核验，避免残留通知激活路径。

本候选未使用商业代码签名证书。不要因为出现来源警告就盲目信任不明下载；应确认来自本项目受审查的发行渠道。

## 设置、暂停、退出

双击程序或开始菜单入口会向已有实例发送有界的本地请求，打开同一个助手的设置；不会创建第二个常驻。关闭设置窗口后，已启用的助手继续后台运行。未同意启用时关闭设置即退出。

设置中可暂停/恢复提醒、配置/暂停唤回、管理登录自启、发送一条明确标记的测试通知、退出与卸载。首次使用不会继承开发者的配置、SID、快捷键或授权。

命令行（用于支持与运维）：

```text
WeChatNotify.exe --settings
WeChatNotify.exe --status
WeChatNotify.exe --pause
WeChatNotify.exe --resume
WeChatNotify.exe --quit
```

没有托盘图标是设计行为，不代表无法关闭。`--status` 在命令提示符中可能无控制台输出，重定向标准输出或直接查看设置中的状态即可。

## 微信更新与降级

只用公开 Windows 接口，不把旧 Qt 路径、内存偏移或窗口坐标套到新版本。官方文件必须通过 Windows Authenticode 本地信任核验及腾讯签名者身份检查。证书链检查限制为缓存，不主动联网刷新吊销信息；信任库不完整的电脑可能核验失败。

本候选已在一台 Windows 11 x64、微信 **4.1.15.56** 的电脑完成明确测试通知点击验收，原微信正常出现且没有托盘展开闪现；这不代表其它机器或每条新消息均已验证。对其他签名正确的版本只作实验性公开事件尝试，并在设置说明未实测，不承诺一定提醒。检测到文件变化时重新核验；旧快捷键绑定不会自动授权新版本的输入操作，需要用户重新确认。

**无微信进程时不会启动微信。** 冷通知激活仅是有时限的临时处理过程，不创建另一套监控常驻。不存在自动下载适配器或自动更新承诺。

## 更新、回滚和卸载

更新：解压新的可信发行包，运行其中的 `Install.cmd`。先校验并暂存完整包，再正常退出本工具，替换自己的固定安装目录；配置留在用户目录，保留一个 `.previous` 安装副本。路径含中文和空格不需手工拼接命令。

回滚：从完整包运行 `Rollback.cmd`，交换当前与上一完整安装。它不恢复微信程序，也不清除事故保护。没有上一完整包时拒绝回滚。未知文件或校验失败会停止处理并保留文件，必要时先备份后处理。

卸载：在设置点“卸载”。移除本工具自己的通知注册、开始菜单入口、自启和已知配置/日志/图标缓存；标准安装还删除清单列出的当前与上一安装文件。便携目录由你最后手动删除。未知文件和事故保护文件保留，避免误删或让保护静默失效。不会删除微信、账号或聊天数据。

## 权限与隐私

使用公开窗口关注事件、只读进程路径/创建时间/所属用户/会话信息，以及本地官方程序签名与图标。默认不发送截图、联系人、消息内容、遥测或任何上传。图标只从用户本机经过验证的微信提取；包内只有自有铃铛图标作为安全回退。

设置和有界技术状态位于 `%LOCALAPPDATA%\WeChatNotify`；二进制目录不写运行日志。状态只记最近事件、错误类型、版本与必要的进程/激活技术信息，不是无限增长日志。快捷键绑定中包含本机 SID 和官方文件哈希，仅本地保存，不随发行包分发。

若检测到打包应用的文件虚拟化，设置/后台入口会请求资源管理器在普通用户上下文启动自身，并再次验证实际打开的配置目录。不能验证则停止，不在错误目录静默初始化配置。

旧工程事故保护限定的危险窗口操作、界面探针在本产品中不存在。已知旧窗口交互事故不会自动授权快捷键；快捷键仍需本用户单独确认。新的本工具事故保护或未知旧事故会阻止唤回，保护文件不会自动过期或被卸载删除。

## 常见问题

**没提醒**：确认助手设置已启用，微信为官方 x64 安装且正在运行；检查 Windows 通知设置。公开关注事件不是逐消息 API。不要靠频繁发送消息、反复点击来验证。

**点击没反应**：看设置中最近唤回状态；确认快捷键、微信版本和输入桌面。勿在按着 Ctrl/Alt/Shift/Win/组合字母时测试。更新、更改组合键或冲突后重新确认；连续失败会暂停。本工具不盲猜按键，也不通过托盘展开来兜底。

**找不到安装**：在设置选择官方 `Weixin.exe` 或 `WeChat.exe`。多份安装、签名不符、远程/重定向目录会拒绝自动选择。

**想报告问题**：先提供版本、Windows 版本和设置中的错误代码。不要提交聊天截图、账号、原始配置或完整用户目录日志。
